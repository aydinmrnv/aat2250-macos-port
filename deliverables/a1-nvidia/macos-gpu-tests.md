# Tests that need macOS and/or this RTX 5090 (A1)

Target: Alienware Area-51 AAT2250, RTX 5090 `10DE:2B85` (subsystem `1028:5305`, VBIOS `98.02.2e.80.06`), Arrow Lake iGPU `8086:7D67`, Dell S3225QS + 2x LG Ultra HD.

Driver: `drv@470e391` (v2.6.6), optionally plus the A1 patch (`patches/a1-nvrm-video-engine-instances.patch`). None of these tests was run. They are specifications.

General rules: keep a known-good OpenCore config with `-nvoff` and the 1401 "Remove NVIDIA driver" entry. Collect `log show --last boot --predicate 'process == "kernel"' | grep -E 'NVRM|NVRM-fb|NVRM-fbinfo|NVAccel'` and `ioreg -r -c IOPCIDevice -l -w0 -k nvrm-gpu-profile` after every boot. Record `sysctl kern.bootargs`.

**Host-side precondition (already measured, D):** under Windows the firmware gives BAR1 = 32768 MiB and VRAM = 32607 MiB (`nvidia-smi -q -d MEMORY`, 2026-11-02).
