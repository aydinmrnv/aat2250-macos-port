### Not recommended or not applicable

- **itlwm.kext** (upstream OpenIntelWireless, 53c51c2c, v2.3.0). It has no 0x272B match. In `itlwm/hal_iwx/ItlIwx.cpp`, the device table at lines 11751-11766 stops at 0x2729, and the IOPCIMatch in `AirportItlwm/Info.plist:32` has no 272B entry (**DEMONSTRATED**). This driver cannot run the BE200.
- **RealtekRTL8111 / RTL8153-specific kexts.** The 0BDA:8153 USB GbE sits inside the WD19TB dock (see usb-topology.md). It is not a motherboard device and needs no kext for first boot.
- **XhciPortLimit quirk.** It is broken on macOS 11.3 and later (PROJECT CLAIM, Dortania). Map ports to 15 or fewer per controller instead.

## Kext order for A2 (`Kernel > Add`)

1. Lilu.kext
2. (A2's platform kexts such as VirtualSMC go here, in their usual order)
3. AppleALC.kext (after Lilu)
4. LucyRTL8125Ethernet.kext
5. BlueToolFixup.kext (after Lilu)
6. IntelBluetoothFirmware.kext
7. IntelBTPatcher.kext (after Lilu and IntelBluetoothFirmware)
8. USBToolBox.kext
9. UTBMap.kext (after USBToolBox), or UTBDefault.kext before the map exists
10. *(phase 2, disabled)* AirportItlwm.kext. It needs `MinKernel`/`MaxKernel` set to the target macOS only.

The old IntelBluetoothInjector must **not** be enabled on macOS 12 or later. The BrcmPatchRAM README:175 says not to combine BlueToolFixup with BrcmBluetoothInjector (PROJECT CLAIM).

**Required NVRAM, for Bluetooth on all macOS versions.** Per BrcmPatchRAM README:177-180 and Changelog v2.7.0 (PROJECT CLAIM), set these under `NVRAM > Add > 7C436110-AB2A-4BBB-A880-FE41995C9F82`:

- `bluetoothExternalDongleFailed` = data `00`
- `bluetoothInternalControllerInfo` = data `0000000000000000000000000000`

Add both keys to `NVRAM > Delete` as well.

**Audio.** Set `DeviceProperties > PciRoot(...)/HDAS` with `layout-id` (data, 4 bytes, little-endian), or pass the boot-arg `alcid=<n>` while testing. The HDAS path is `ACPI(_SB_)#ACPI(PC02)#ACPI(HDAS)`, which sits under PC02, the second root bridge. A2 must turn that into a PciRoot path from macOS (gfxutil) or Windows; A3 has not derived the device path.
